Disk-only clone RFC #625

Cold-boot fresh, fully independent VMs from a captured disk — free choice of memory, CPU, and hugepages. The abstraction, verified reuse seams, fc-agent storage policy, and a green-at-every-step stacked-PR plan.

Disk performance measurements
